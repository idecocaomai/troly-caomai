CÙNG NHAU CHIA SẺ CÔNG NGHỆCÙNG NHAU KIẾM KHÁCH HÀNG VÀ DOANH THU TỐT HƠN

Hỏi bất cứ điều gì về sản phẩm, khách hàng, quy trình. Gửi kèm PDF, Word, Excel để trợ lý đọc và phân tích. Bật tra cứu web khi cần số liệu mới.

Project

Mỗi việc một bộ chỉ dẫn

Tạo project trong ⚙ Cài đặt, viết chỉ dẫn riêng cho AI (giọng văn, dữ liệu nền, cách trả lời). Chọn project nào thì AI làm theo chỉ dẫn của project đó.

Firebase

Một máy khai, cả công ty dùng

Khóa API và toàn bộ project được đồng bộ qua Firebase Realtime Database. Máy khác mở lên là có sẵn, không cần khai lại.

Nghiên cứu

Model tự chọn trang mà đọc

Trợ lý tự suy ra cần vào trang nào, mở ra đọc toàn văn, tự đánh giá còn thiếu gì rồi đi tiếp vòng sau. Trích dẫn có đánh số kèm đường dẫn nguồn.

Tài liệu

File dài vẫn phân tích được

PDF, Word, Excel, PowerPoint được đọc ngay trên máy bạn. File quá dài thì trợ lý chia phần đọc từng đoạn rồi tổng hợp lại.

Nhúng

Chép một khối là xong

Chép nguyên khối giữa hai mốc SCRIPT-BEGIN và SCRIPT-END rồi dán trước thẻ </body>. Widget chạy trong Shadow DOM, không đụng CSS hay id của trang.
